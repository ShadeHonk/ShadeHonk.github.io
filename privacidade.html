Política de privacidade

Última atualização: 1º de novembro de 2026.

O Manhwa Recap Studio é uma ferramenta pessoal que roda no computador do próprio usuário. Esta política explica como ela usa os dados da conta do Google.

Dados acessados

  • Envio ao YouTube (escopo youtube.upload): usado somente para enviar vídeos e thumbnails ao canal do próprio usuário, quando ele pede.
  • Leitura do YouTube (escopo youtube.readonly): usado somente para identificar o canal conectado e conferir os vídeos já enviados.

Armazenamento

A autorização do Google fica guardada apenas no computador do usuário, protegida pelo Windows. Nenhum dado da conta é enviado a servidores do Manhwa Recap Studio, porque eles não existem.

Compartilhamento

Os dados não são vendidos, compartilhados nem usados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions ou pelo botão Desconectar do próprio Studio.
